# AC Cool N Care Website Mockup

## Files
- `index.html` — homepage structure and content
- `style.css` — responsive Blue / White / Orange theme
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a browser. Internet is required for Google Fonts and the sample Unsplash images.

## Important before publishing
1. Replace sample photos with real company/project photos you own or are licensed to use.
2. Confirm phone number, email, actual service areas, operating hours and service claims.
3. Replace the placeholder review section with genuine reviews only.
4. Connect the quote CTA to a real WordPress form (e.g. your installed form plugin); the current button jumps to the contact section.
5. Replace Privacy Policy and Terms placeholder links with your real pages.
6. Test mobile, forms, links, image loading, accessibility, SEO metadata and performance on staging.

## WordPress integration
This is a static frontend mockup, not an installable WordPress theme ZIP. For a theme, these files need to be converted into WordPress templates (`header.php`, `footer.php`, `front-page.php`, `functions.php`, etc.) and enqueued properly.
